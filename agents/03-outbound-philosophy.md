# Outbound Philosophy

## Goal

Trigger "this is us."

## Not The Goal

- Explain product deeply
- Pitch features first

## Outbound Rules

1. Anchor to their context.
2. Use micro-output.
3. No links upfront.
4. One ask per message.
5. Trial ask comes last.

## Outbound Flow

1. Find pain
2. Reply with insight
3. Wait
4. Continue
5. Offer run
6. Deliver artifact
