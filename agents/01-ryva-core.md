# Ryva Core

## What Is Ryva

Ryva is a decision layer for dev teams.

It reads activity from:

- GitHub (PRs, commits, issues)
- Slack (discussions, threads)

And outputs:

- Decisions made
- Missing decisions
- Blockers and risks
- Next actions

Ryva is not a summarizer.

It does not just compress information.
It surfaces what should happen next and why.

## Core Insight

Standups and meetings exist because project state is not visible anywhere else.

Ryva reduces reconstruction overhead by making decisions and gaps explicit.
