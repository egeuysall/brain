# ICP And Conversion

## Ideal Customer Profile

- Founder, CTO, or Engineering Manager
- 3-15 dev team
- Actively shipping

## ICP Signals

- "We lose context"
- "Standups do not work"
- "Things slip"

## Conversion Loop

1. Conversation
2. Repo or PR
3. Run Ryva
4. Clean output
5. Send insight
6. Ask: "is this useful or just interesting?"
