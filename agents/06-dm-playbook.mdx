# DM Playbook

## Goal

Start conversation, trigger recognition, then move to run.

## Step 1: Opener (Mirror + Micro-Output)

```text
hey saw your comment about [specific thing]

this might be off but something like:

[concrete situation]

is that close?
```

## Step 2: Confirmation

If they confirm pain, mirror the exact phrasing they used.

## Step 3: One Insight

Provide one concrete decision-gap insight.

## Step 4: Ask

Use one low-friction ask:

```text
want me to run this on one public PR and send a clean output?
```

## Step 5: Deliver

Send artifact in this order:

1. Action line
2. Missing decisions
3. Risk
4. One question
