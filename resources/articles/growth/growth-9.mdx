# 📊 REPORTING FRAMEWORK

### 31. Monthly Growth Report Template

**Context**: Structured reporting drives consistency
**Why Test This**: Can’t improve what you don’t measure

**Framework**:

```
[Company] Growth Report - [Month Year]

🎯 KEY METRICS
- MRR: $X (+/- X% vs last month)
- New Customers: X (+/- X%)
- Churn Rate: X% (+/- X%)
- Trial→Paid: X% (+/- X%)

🚀 WINS
1. [Achievement with number]
2. [Achievement with number]
3. [Achievement with number]

⚠️ CHALLENGES
1. [Issue + impact]
2. [Issue + impact]

📈 TOP CHANNELS
1. [Channel]: X conversions, $Y CAC
2. [Channel]: X conversions, $Y CAC

🧪 TESTS RUN
✅ Winner: [Test] - [result]
❌ Loser: [Test] - [result]
🔄 Running: [Test] - [status]

🎯 NEXT MONTH PRIORITIES
1. [Goal with success metric]
2. [Goal with success metric]
```

**Test Variables:**

- Frequency: Monthly vs. weekly
- Distribution: Email vs. dashboard vs. meeting
- Metric selection: Which KPIs to track
- Format: Slides vs. doc vs. dashboard
