# 🤝 PARTNERSHIP OUTREACH FRAMEWORKS

### 29. Integration Partner Pitch

**Context**: Strategic partnerships expand reach
**Why Test This**: Shared customers want connected tools

**Framework**:

```
Subject: [Your Product] + [Their Product] integration idea

Hi [Name],

We both serve [ICP segment].

Getting requests from mutual customers to integrate [Your Product] and [Their Product] for [workflow].

They're currently doing this manually via [workaround].

An integration could:
→ [Benefit for end user]
→ [Benefit for both products]
→ [Benefit for end user]

Worth 15 mins to explore?

[Your Name]

P.S. [Number] mutual customers who've requested: [Examples]
```

**Test Variables:**

- Timing: Before building vs. after MVP
- Customer proof: List vs. count only
- Ask: Call vs. email discussion
- Value emphasis: User benefit vs. mutual benefit

### 30. Co-Marketing Proposal

**Context**: Shared audience marketing
**Why Test This**: Splits cost and effort

**Framework**:

```
Subject: Co-marketing idea for [target audience]

[Name],

Our audiences overlap - both targeting [ICP] dealing with [challenge].

Idea: Co-host [webinar/report/content] on "[Topic]"

Your contribution: [expertise area]
Our contribution: [expertise area]

Value for you:
→ Access to our [X]-person list
→ 50/50 lead split
→ Co-promotion across channels

Value for audience:
→ Complete solution to [problem]

15-min call to discuss?

[Your Name]
```

**Test Variables:**

- Asset type: Webinar vs. ebook vs. video series
- Lead split: 50/50 vs. each keeps own
- Investment: Time only vs. also budget
- Audience size transparency: Share vs. vague
