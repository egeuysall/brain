# 💰 PRICING & MONETIZATION FRAMEWORKS

### 45. Pricing Page Structure

**Context**: Pricing page optimization can significantly impact conversions
**Why Test This**: Reduces friction at decision point

**Framework**:

```
HEADLINE: "Simple Pricing for [ICP]"

SUBHEADLINE: "Join [X] [companies/teams] using [Product]"

[3 TIERS MAXIMUM]

STARTER - $X/mo
"For [segment] getting started"
✓ [Feature]
✓ [Feature]
✓ [Feature]
✓ [Support level]
[Limits]
[CTA: Start Free Trial]

PROFESSIONAL - $Y/mo ⭐ POPULAR
"For [segment] who need [capability]"
✓ Everything in Starter
✓ [Premium feature]
✓ [Premium feature]
✓ [Better support]
[Higher limits]
[CTA: Start Free Trial]

ENTERPRISE - Custom
"For [segment] with [needs]"
✓ Everything in Pro
✓ [Enterprise feature]
✓ [Enterprise feature]
✓ Dedicated support
✓ Unlimited [resource]
[CTA: Contact Sales]

**FAQ:**
- Can I change plans? → Yes, anytime
- Payment methods? → All major cards + [other]
- Refunds? → [Policy]
- Need more? → Custom plans available

**Trust Signals:**
→ No credit card for trial
→ Cancel anytime
→ [Security badges]
→ [X]-day money-back guarantee

[Detailed comparison table below]
```

**Test Variables:**

- Tier count: 2 vs. 3 vs. 4
- Anchor pricing: Show annual vs. monthly
- Feature list: Comprehensive vs. highlights only
- Social proof: Logos vs. testimonials vs. stats

### 46. ROI Calculator Page

**Context**: Interactive tools increase engagement and perceived value
**Why Test This**: Helps prospects quantify value

**Framework**:

```
HEADLINE: "Calculate Your ROI with [Product]"

CALCULATOR:
"Tell us about your situation:"

1. [Relevant metric] per month?
   [Slider or input]

2. Time spent per [unit]?
   [Dropdown options]

3. Average hourly rate?
   [$____ input]

4. Current solution cost?
   [$____/month input]

[CALCULATE BUTTON]

**RESULTS:**
💰 Monthly Savings: $[X]
⏰ Time Saved: [Y] hours
📈 ROI: [Z]% in 3 months
🎯 Payback: [N] days

"[Customer] saved $[X] in first quarter"

[CTA: See How It Works]
[CTA: Start Free Trial]

**The Math:**
Current cost: $[A]
[Product] cost: $[B]
Time value: $[C]
Other savings: $[D]
= Net savings: $[E]/month
```

**Test Variables:**

- Input count: 3 vs. 5 vs. 7
- Input type: Slider vs. dropdown vs. text
- Results display: Simple vs. detailed
- CTA placement: With results vs. below vs. both
