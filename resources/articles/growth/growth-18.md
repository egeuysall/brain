# SECTION 1: FOUNDATION (Do First)

## 1. The 5-Minute Landing Page

**Template:**

```
Headline: [Do X] without [pain] in [time]
Subheadline: [How it works in one sentence]
CTA: "Try free" or "Join waitlist"

3 Features:
✓ [Benefit 1]
✓ [Benefit 2]
✓ [Benefit 3]

Final CTA: Big button "Start now - free"

```

**Tools:** Carrd ($19/year), Notion (free), Typedream (free)

---

## 2. Your One-Liner Formula

**Fill in the blanks:**

```
[Product] helps [specific person] [achieve outcome] without [pain point]

Example: "Taskly helps solo founders track customer feedback without messy spreadsheets"

```

Use this everywhere: bio, DMs, emails, posts.

---

## 3. The "Build in Public" Setup

**Where to post:** Twitter/Threads (pick one)

**What to post (3x/week minimum):**

- Monday: Weekly metrics update
- Wednesday: Feature you're building + why
- Friday: Lesson learned or user win

**Template:**

```
Building [Product] in public:
- Users: [X] (+Y this week)
- Today's focus: [What you're working on]
- Key lesson: [One thing]

Ask me anything! 🧵

```
