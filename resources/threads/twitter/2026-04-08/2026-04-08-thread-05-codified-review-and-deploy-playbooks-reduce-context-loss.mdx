```text
@akshay_pachaar This is the right mental model. CLAUDE.md = constitution, Skills = specialized playbooks. We moved our deploy checklist, PR review flow, and test scaffolding into separate skills. Context usage dropped noticeably and Claude stopped "forgetting" mid-session.
```

## Why It Matches Ryva ICP

Small teams turning repeated review/deploy routines into explicit playbooks. Strong match for teams where process knowledge is trapped in individual memory.

## Underlying Problem

Operational checklists live in people, so handoffs and agent-assisted workflows degrade when the original author is unavailable.

## Suggested Public Response (Copy)

```text
Encoding repeatable flows as explicit playbooks is a practical step. It cuts re-explaining overhead and keeps review/deploy quality more stable across sessions. The win is not “more AI,” it is durable process memory that survives context switches and personnel changes.
```
