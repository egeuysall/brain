## Post Text (Key Excerpt)

```text
Ask a team where their pipeline lives. They will say: "our CRM." But the actual work is in Slack, emails, side notes, and memory. That is where things break: missed follow-ups, lost context, duplicate work.
```

## Why It Matches Ryva ICP

It captures a small-team operating reality: official systems say one thing while real decisions and execution live in Slack and ad-hoc channels.

## Underlying Problem

Execution state is reconstructed from scattered artifacts, so ownership and follow-through degrade.

## Suggested Public Response (Copy)

```text
This is exactly the hidden failure mode. Systems of record lag reality, so teams end up coordinating from memory instead of shared state. The fix is capturing decision, owner, and next action at the moment work changes.
```
