```text
PR review quality improves when reviewers can reason about repo context, not only the diff.
```

## Why It Matches Ryva ICP

Direct engineering workflow signal around review bottlenecks, context quality, and hidden risk in approval loops.

## Underlying Problem

Reviewers approve local changes without enough global context, causing downstream regressions and slow feedback cycles.

## Suggested Public Response (Copy)

```text
Exactly right: review speed without context usually creates rework. The useful shift is from "did this diff compile" to "does this change preserve system behavior and ownership boundaries." Teams that encode risk class + rollback trigger in PRs catch more issues earlier.
```
