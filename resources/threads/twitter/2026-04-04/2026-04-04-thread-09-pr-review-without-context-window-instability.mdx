## Why It Matches Ryva ICP

It flags inconsistent PR review quality caused by missing context packaging, common in fast-moving dev teams.

## Underlying Problem

Review pipelines are non-deterministic because input context and standards are not pinned.

## Suggested Public Response (Copy)

```text
This is usually a packaging issue, not just a model issue. If review context is unstable, outputs drift day to day. Teams get better reliability by freezing a review bundle: diff, touched modules, risk checklist, and repo conventions. Same bundle in, comparable signal out.
```

## Suggested DM Idea (Copy)

```text
Is your PR review input bundle versioned, or rebuilt ad hoc each run?
```
