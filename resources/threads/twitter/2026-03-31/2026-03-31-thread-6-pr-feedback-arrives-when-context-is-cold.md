## Post Text (Key Excerpt)

```text
Feedback comes at review time after the code is written, the context is cold, and the reviewer is starting from scratch. The brief should come before the diff, not after.
```

## Why It Matches Ryva ICP

It describes timing mismatch in real PR workflow where feedback arrives too late for efficient decisions.

## Underlying Problem
